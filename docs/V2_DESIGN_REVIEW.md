# V2 设计与体验审查

日期：2026-11-03  
审查基线：`cef5ee3`（Git 标签 `v1-workbuddy`）

## 审查结论

V1 的课程、练习、统计、离线与数据闭环完整，WorkBuddy 根据 Anti-Gravity 意见处理的 11 项 P0/P1/P2 均可在代码和浏览器验证中对应。V2 不改变 42 项已确认决策、课程规则或评分逻辑，只升级界面系统并补足一个窄屏缺陷。

| P3 | 生产包主 JS 超过 500 kB，构建会提示拆包建议 | 当前不影响离线或运行；保留为后续性能优化项，避免本轮引入路由加载风险 |

## V2 设计原则

1. 内容先于装饰：练习输入框、键位图、状态和错误反馈保持最高对比度。
2. 克制的品牌叙事：鹤只作为首页视觉锚点，内页依靠材质与排版连续，不重复堆图。
3. 动效解释状态：悬停表示可进入，按压表示已触发，键帽位移表示输入；不使用循环干扰动效，主视觉漂浮也受“关闭动画”和系统减少动画控制。
4. 本地优先可信感：首屏明确“无账号、无上传、可离线”，与真实存储行为一致。
5. 渐进适配：桌面双栏 Hero、平板弱化背景、小屏转为背景式主视觉；390px 无横向滚动。
